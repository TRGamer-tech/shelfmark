Until then everything works except borrowing. Friends need this version too: an older one is told that it is too old to ask for a book.

## Borrowing, for real

A borrow request used to be a note passed between two phones, and nothing followed from it. A loan is now one record that both of you see, and every step changes something.

- **Ask.** On a friend's shelf, as before. The friend finds your question on the book itself and under **Loans**, which replaces the list of requests.
- **Yes means reserved.** Nobody else can ask for the book now. With the yes comes a day the book is wanted back by, or "no fixed date". A no can carry a reason, and if somebody else got the book you are told so and can ask again later.
- **Handing over takes both of you.** The lender says "I handed it over", the borrower says "I have it". Only then is the book lent.
- **The borrowed book stands on your own shelf**, as borrowed, ready to be read, rated and quoted from.
- **Giving back takes both of you too.** The borrower says "I gave it back", the lender says "I have it back". The lender's book is free again, and the borrower keeps their copy as "read, not mine", with everything they noted in it.
- **A reminder when the day has come**, for both. The lender can change the day at any time.
- Either side can step back as long as the book has not changed hands, and you can always ask again.
- The app now looks for news every minute while it is open, not only when it is opened.

Borrowing needs both sides signed in. Showing a shelf as a file to somebody without an account still works, and so does lending by hand to somebody who does not use Shelfmark.
